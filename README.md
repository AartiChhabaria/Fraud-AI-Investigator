# Explainable AI Fraud Detection System

This project detects fraudulent credit card transactions using XGBoost and explains predictions using SHAP.

## Features

- Fraud Detection
- SHAP Explainability
- Risk Scoring
- Investigation Report Generation
- Streamlit Dashboard

## Technologies

- Python
- XGBoost
- SHAP
- Streamlit
- Scikit-Learn
